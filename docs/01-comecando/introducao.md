# O que é o Umbra Bot

**TL;DR:** O Umbra Bot conecta o seu bot do Telegram a um sistema completo de vendas — captura leads, recebe pagamentos via PIX e mostra tudo em um painel centralizado.

---

## Para quem é o Umbra Bot

O Umbra Bot foi feito para quem vende no digital: infoprodutores, criadores de conteúdo, coaches, consultores e qualquer pessoa que queira usar o Telegram como canal de vendas.

Se você já tem — ou quer ter — um bot no Telegram para capturar clientes e receber pagamentos, o Umbra Bot é a plataforma que faz tudo isso funcionar de forma organizada.

---

## O que você consegue fazer

Com o Umbra Bot, você pode:

- **Capturar leads automaticamente** — toda pessoa que manda `/start` pro seu bot vira um contato na sua lista
- **Receber pagamentos via PIX** — integrado ao Mercado Pago, sem precisar de nenhum sistema externo
- **Ver suas vendas em tempo real** — painel com receita, número de vendas e bots ativos
- **Monitorar seus bots** — o sistema avisa se algum bot desconectar
- **Gerenciar afiliados** — crie um programa de afiliados e acompanhe as comissões

---

## Como funciona na prática

```
Seu cliente                Seu bot no Telegram              Umbra Bot
─────────────              ───────────────────              ──────────
Manda /start   →   Bot responde automaticamente   →   Lead registrado
Clica no link  →   Abre página de pagamento        →   PIX gerado
Paga           →   Recebe confirmação              →   Venda no painel
```

O seu bot no Telegram é a "porta de entrada". O Umbra Bot é o sistema que funciona nos bastidores: registra os leads, processa os pagamentos e entrega os relatórios.

---

## O que você precisa para começar

Antes de configurar tudo, separe:

1. **Uma conta no Telegram** — para criar o seu bot
2. **Uma conta no Mercado Pago** — para receber os pagamentos via PIX
3. **Uma conta no Umbra Bot** — gratuita para criar

> **Dica:** Você consegue criar tudo isso em menos de 30 minutos. O artigo [Do zero ao primeiro PIX](./primeiro-pix.md) te leva passo a passo.
