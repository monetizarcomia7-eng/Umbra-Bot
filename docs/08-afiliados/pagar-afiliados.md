# Pagar comissões para afiliados

**TL;DR:** Na aba "Pagamentos", selecione os registros que você pagou e clique em "Marcar como pago". O sistema registra a data e o histórico fica salvo.

---

## Como funcionam os pagamentos de comissão

O Umbra Bot registra automaticamente as comissões geradas por cada venda. O pagamento em si — a transferência do dinheiro para o afiliado — é feito manualmente por você, fora do sistema (via PIX, por exemplo).

Depois de fazer o pagamento, você marca no sistema para manter o controle.

---

## Acessar a aba de Pagamentos

Na tela de **Afiliados**, clique na aba **"Pagamentos"**.

<!-- screenshot: aba "Pagamentos" na tela de Afiliados -->

Você vê uma lista com:
- Nome do afiliado
- Ciclo de referência (período das vendas)
- Número de vendas no ciclo
- Valor a pagar
- Status (Pendente / Pago)

---

## Marcar comissões como pagas

**1.** Use as caixas de seleção para marcar os registros que você já pagou

**2.** Clique em **"Marcar como pago"** na barra que aparece no topo

<!-- screenshot: registros selecionados com botão "Marcar como pago" visível -->

**3.** Os registros mudam para o status **"Pago"** com a data do pagamento registrada

---

## Fazer o pagamento de fora do sistema

O Umbra Bot não transfere dinheiro para os afiliados automaticamente — você precisa fazer a transferência manualmente (via PIX, TED, etc.) e depois marcar como pago no sistema.

**Fluxo recomendado:**

1. Veja quanto cada afiliado tem a receber na aba Pagamentos
2. Faça a transferência via PIX para o afiliado
3. Volte ao sistema e marque como pago

## Histórico de pagamentos

Todos os pagamentos marcados ficam no histórico com a data de quando foram registrados. Você pode filtrar por status (Pendente / Pago) para ver rapidamente o que ainda precisa ser pago.
