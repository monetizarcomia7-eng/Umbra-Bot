# Filtrar e ordenar clientes

**TL;DR:** Use os filtros no topo da lista para segmentar por status, origem, tag ou período. A ordenação funciona clicando nos cabeçalhos das colunas. Tudo é salvo automaticamente.

---

## Filtros disponíveis

### Busca por nome

Digite o nome ou @usuário do cliente no campo de busca. A lista atualiza enquanto você digita.

<!-- screenshot: campo de busca com termo digitado -->

### Status

Filtra por:
- **Todos** (padrão)
- **Compradores** — apenas quem já comprou
- **Leads** — apenas quem ainda não comprou

### Origem

Filtra pelo canal de onde o contato veio (ex: instagram, google, direto).

> **De onde vem a origem?** É preenchida automaticamente quando você usa links com parâmetros de rastreamento UTM. Se estiver vazia, o contato entrou sem rastreamento.

### Tag

Filtra por tag adicionada manualmente. Útil para segmentar grupos específicos (ex: "VIP", "lista-espera", "evento-junho").

### Período

Filtra pelos contatos que entraram no bot dentro de uma janela de tempo (7, 30 ou 90 dias).

---

## Ordenar a lista

Clique no cabeçalho de qualquer coluna para ordenar por aquele critério. Clique novamente para inverter a ordem (crescente/decrescente).

Colunas com ordenação disponível:

- Nome (A→Z ou Z→A)
- Origem
- Status
- Compras (maior→menor)
- Total gasto (maior→menor)
- Último contato (mais recente→mais antigo)

<!-- screenshot: coluna "Total gasto" com seta de ordenação ativa -->

---

## Os filtros são salvos

O Umbra Bot salva automaticamente os filtros e a ordenação que você usou. Quando você sair e voltar para a tela de Clientes, os filtros continuam aplicados — não precisa configurar de novo.

Para limpar todos os filtros de uma vez, clique em **"Limpar filtros"**.

---

## Adicionar tags em massa

Se você quiser adicionar uma tag para vários clientes ao mesmo tempo:

1. Selecione os clientes usando as caixas de seleção na lista
2. Clique em **"Adicionar tag"** na barra que aparece no topo
3. Digite o nome da tag e confirme

<!-- screenshot: múltiplos clientes selecionados com opção "Adicionar tag" aparecendo -->

A tag é adicionada para todos os selecionados de uma só vez, sem duplicar quem já tinha aquela tag.

---

## Exportar a lista filtrada

Com os filtros que quiser aplicados, clique em **"Exportar CSV"** para baixar a lista atual em planilha.

O arquivo inclui: nome, @usuário, e-mail, telefone, origem, tags, status, compras, total gasto e data de entrada.
