# O feed de atividade

**TL;DR:** O feed de atividade é um registro cronológico de tudo que acontece — cada novo lead, venda, reconexão de bot e muito mais. Você pode ver ao vivo ou filtrar o histórico.

---

## Como acessar

No menu lateral, clique em **"Atividade"**.

<!-- screenshot: menu lateral com "Atividade" destacado -->

---

## O que aparece no feed

Cada linha do feed é um evento. Os tipos mais comuns:

| Tipo | O que significa |
|---|---|
| **Novo lead** | Alguém mandou `/start` para um dos seus bots |
| **Venda realizada** | Uma transação foi aprovada |
| **Pagamento recebido** | Pagamento PIX confirmado |
| **Bot reconectado** | Um bot que estava offline voltou a funcionar |
| **Bot desconectado** | Um dos seus bots perdeu conexão com o Telegram |
| **Reembolso** | Uma venda foi revertida |

Cada evento mostra:
- Ícone e cor indicando o tipo
- Título descritivo
- Nome do bot envolvido
- Tempo relativo (ex: "há 3 minutos")

---

## Modo ao vivo

Clique no botão **"Ao vivo"** no topo da página para ativar o feed em tempo real.

<!-- screenshot: botão "Ao vivo" ativo com badge vermelho mostrando contagem -->

Com o modo ao vivo ativo:
- Novos eventos aparecem automaticamente no topo da lista sem precisar atualizar a página
- Um badge vermelho mostra quantos eventos novos chegaram desde a última vez que você olhou para o topo

Para voltar à posição mais recente, role até o topo — o contador zera automaticamente.

---

## Navegar para o contexto

Cada evento tem um botão **"Ver"** que leva direto para a área relacionada:

- Evento de venda → abre o painel **Financeiro**
- Evento de lead → abre a tela de **Clientes**
- Evento de bot → abre **Gerenciar Bots**
