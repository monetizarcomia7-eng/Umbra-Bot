# Filtrar o histórico de atividade

**TL;DR:** Use os filtros no topo do feed para ver apenas os eventos que importam — por tipo, bot, período ou palavra-chave. Os filtros são salvos automaticamente para a próxima visita.

---

## Filtros disponíveis

### Categoria

Filtra por tipo de evento:

| Opção | O que mostra |
|---|---|
| **Todos** | Todos os eventos (padrão) |
| **Vendas** | Apenas vendas realizadas |
| **Leads** | Apenas novos leads |
| **Pagamentos** | Pagamentos e reembolsos |
| **Bots** | Conexões e desconexões de bots |
| **Sistema** | Alertas e eventos do sistema |

### Bot

Filtra os eventos de um bot específico. Útil quando você tem vários bots e quer ver o que aconteceu em cada um separadamente.

### Período

| Opção | Janela de tempo |
|---|---|
| **Tudo** | Todo o histórico (padrão) |
| **7 dias** | Última semana |
| **30 dias** | Último mês |
| **90 dias** | Últimos 3 meses |

> **Nota:** O histórico de atividade é mantido por **90 dias**. Eventos mais antigos são removidos automaticamente. Para guardar um registro permanente, exporte os dados em CSV.

### Busca por texto

Digite qualquer palavra que apareça no título ou na descrição do evento. O feed filtra em tempo real enquanto você digita.

**Exemplos de busca:**
- Nome de um cliente ("João Silva")
- Nome de um bot ("@meubot")
- Valor de uma venda ("297")

---

## Limpar os filtros

Clique em **"Limpar filtros"** para voltar à visualização completa sem nenhum filtro aplicado.

Os filtros são salvos automaticamente entre sessões. Se você sair e voltar depois, os filtros que usou na última vez ainda estarão aplicados.

---

## Carregar eventos mais antigos

O feed começa mostrando os eventos mais recentes. Para ver eventos mais antigos (dentro do limite de 90 dias), role até o final da lista e clique em **"Carregar mais"**.
